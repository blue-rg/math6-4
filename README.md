# 픽셀 비례 낚시터 — 깃허브 페이지 + 파이어베이스 온라인판 설치 방법

6-2 4단원 「비례식과 비례배분」 **단원 복습용 2D 픽셀 낚시 게임**이에요(혼자 하는 게임). 게임 화면은 **깃허브 페이지(GitHub Pages)** 에 올리고, 학생 기록(코인·장비·도감)과 **반별 순위**는 **파이어베이스 Realtime Database** 에 저장해요. 그래서 학생이 다른 기기에서 같은 이름·반 코드로 들어와도 이어서 할 수 있어요.

> 인터넷 설정 없이 바로 쓰려면 `픽셀비례낚시_게임.html` 한 파일만 열어도 돼요(기록은 그 기기 브라우저에만 저장되고 반별 순위는 없어요).

## ⚡ 다른 게임(눈싸움·숨바꼭질·랠리)을 이미 설치했다면 (5분)
같은 파이어베이스 프로젝트를 그대로 써요. 이 게임은 데이터베이스의 `snow/fish/` 아래에 따로 저장해서 **다른 게임과 기록이 섞이지 않아요**(규칙도 바꾸지 않아도 돼요).
1. 이미 쓰던 저장소의 `firebase-config.js` 를 이 폴더의 `firebase-config.js` 자리에 **그대로 복사**해요.
2. 아래 5~6단계처럼 **새 저장소**(예: `pixel-fishing`)를 만들어 이 폴더 파일을 올리고 깃허브 페이지를 켜요.

## 폴더에 든 파일
| 파일 | 하는 일 |
|---|---|
| `index.html` | 게임 화면 (고치지 않아도 돼요) |
| `firebase-config.js` | **선생님이 채우는 파일** — 파이어베이스 연결 정보와 선생님 비밀번호 |
| `lib/` | 파이어베이스 9.23.0(Apache-2.0) 도구와 라이선스, 갈무리 픽셀 글꼴(SIL OFL 1.1) 라이선스 |
| `database.rules.json` | 데이터베이스 규칙(3단계에서 붙여넣기) |
| `README.md` | 이 설명 |

## 처음 설치한다면
### 1. 파이어베이스 프로젝트 만들기
1. https://console.firebase.google.com 에 구글 계정으로 들어가요.
2. **프로젝트 추가(만들기)** → 이름 예: `math-604` → (구글 애널리틱스는 꺼도 돼요) → 만들기.

### 2. Realtime Database 만들기
1. 왼쪽 메뉴 **빌드(Build) → Realtime Database** → **데이터베이스 만들기**.
2. 위치는 가까운 **싱가포르(asia-southeast1)** 를 골라요.
3. 보안 규칙은 **잠금 모드**로 시작해요(다음 단계에서 바꿔요).

### 3. 규칙 넣기
**규칙** 탭에서 내용을 모두 지우고 `database.rules.json` 내용을 붙여넣은 뒤 **게시**해요.
```json
{
  "rules": {
    ".read": false,
    ".write": false,
    "snow": { ".read": true, ".write": true }
  }
}
```
- 게임 자료는 모두 `snow` 아래(이 게임은 `snow/fish`)에만 저장돼요.
- ⚠️ 로그인 없이 쓰는 게임이라, 게임 주소를 아는 사람은 `snow` 아래 자료를 읽고 쓸 수 있어요. 주소는 우리 반에만 알려 주세요.

### 4. 웹 앱 등록하고 설정값 복사하기
1. 왼쪽 위 **⚙️ → 프로젝트 설정** → 아래 **내 앱**에서 **웹(`</>`)** 아이콘.
2. 앱 닉네임(예: `픽셀낚시`) → **앱 등록** (Firebase 호스팅은 체크하지 않아요).
3. 나오는 `const firebaseConfig = { ... }` 안의 값을 복사해요. **databaseURL이 꼭 있어야 해요.**
4. `firebase-config.js` 를 메모장으로 열어 `window.FIREBASE_CONFIG = { ... }` 안을 복사한 값으로 바꾸고, 맨 아래 `window.TEACHER_PIN = '4826';` 처럼 선생님 비밀번호를 정해 저장해요.

### 5. 깃허브 저장소에 올리기
1. https://github.com 로그인 → 오른쪽 위 **+ → New repository**.
2. 이름 예: `pixel-fishing` · **Public** → **Create repository**.
3. **uploading an existing file**(또는 **Add file → Upload files**)을 눌러 **`index.html`, `firebase-config.js`, `lib` 폴더(통째로), `database.rules.json`, `README.md`** 를 끌어다 놓고 **Commit changes**.

### 6. 깃허브 페이지 켜기
1. 저장소 **Settings → Pages** → **Source: Deploy from a branch**, **Branch: main / (root)** → **Save**.
2. 1~3분 뒤 나오는 주소 **`https://내아이디.github.io/pixel-fishing/`** 가 학생에게 나눠 줄 게임 주소예요.
3. 첫 화면에 "⚠️ 온라인 기록 준비가 덜 됐어요"가 보이면 `firebase-config.js` 값을 다시 확인해 주세요.

## 수업에서 쓰는 법
1. 학생은 **이름**과 **반 코드**(예: `옥정초604`)를 쓰고 **▶ 낚시 시작**. 문제는 항상 4단원 전 범위(1~6차시 + 단원 마무리)에서 나와요.
2. **던지기 → 입질(찌가 쑥!) → 2.5초 안에 챔질 → 문제 풀기 → 잡기 게이지 100% → 포획 판정**.
3. 잡은 물고기를 **🏪 상점**에서 팔아 낚싯대·낚싯줄·미끼·양동이(각 5단계)를 사요.
4. 상점의 **🎫 티켓** 칸에서 다음 장소의 입장 티켓을 사면 **🗺️ 장소**에서 갈 수 있어요. 티켓은 앞 장소부터 차례로: 맑은 계곡 🪙600 → 푸른 바다 🪙1,500 → 얼음 호수 🪙3,500 → 깊은 밤바다 🪙7,000 (모두 5곳, 물고기 39종).
5. 첫 화면의 **🏆 우리 반 낚시 순위**(판매 금액·도감 수집·맞힌 문제·물고기 크기)는 물고기를 팔거나 문제를 풀 때마다 저장돼요.
   - **물고기 크기** 순위는 물고기 종류마다 우리 반에서 가장 크게 잡은 3명을 보여 줘요. 게임 안 **📖 도감**의 물고기 카드에도 같은 순위가 나와요(반 코드를 쓴 깃허브·파이어베이스판에서만).
6. **📝 오답** 버튼으로 틀린 문제와 풀이를 다시 볼 수 있어요.

## 게임 규칙(숫자)
| 항목 | 값 |
|---|---|
| 잡기 게이지 | 정답 1개마다 `100 ÷ 물고기 힘 × 낚싯대 배율 × 문제 단계 배율(⭐1 · ⭐⭐1.15 · ⭐⭐⭐1.35)` % |
| 틀리거나 시간 초과 | 낚싯줄 ❤ -1, 게이지 -10%. ❤가 0이 되면 줄이 끊어져 달아나요 |
| 문제 | 미리 정한 문항표 대신 32가지 유형에서 숫자·상황을 매번 새로 뽑아 만들어요(최근 300문제와 같은 문제는 다시 뽑음). 정답은 외항의 곱 = 내항의 곱 등으로 한 번 더 확인해요. 유형별 예시는 `문항유형_예시.csv` |
| 포획 확률 | 물고기마다 고정(흔함 82~92% · 보통 62~75% · 희귀 35~50% · 전설 15~25%) |
| 크기·값 | 크기는 물고기별 범위 안에서 무작위(작은 쪽이 더 자주), 값 = 기본값 × 0.6~1.4(클수록 비쌈) |
| 정답 보너스 | ⭐ 1 · ⭐⭐ 2 · ⭐⭐⭐ 3 코인(판정에서 놓쳐도 남아요) |
| 문제 단계 | 흔한 물고기는 ⭐ 위주, 희귀·전설 물고기는 ⭐⭐⭐가 자주 나와요 |
| 제한 시간 | 4지선다 25·30·35초, 숫자 입력 45·55·65초(⭐·⭐⭐·⭐⭐⭐) |
